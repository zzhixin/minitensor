# minitensor

用于学习自动求导的 C 语言项目, 各版本独立编译运行.

| 版本 | 主要实现 |
| --- | --- |
| v0 | 使用 Operator 结构体组织算子 |
| v1 | 使用独立算子函数, 递归遍历依赖路径进行反向传播 |
| v2 | 使用无重复的后序 DFS 构建拓扑序, 再逆序反向传播 |
| v3 | 使用 Graph 统一管理堆上的节点, 支持拓扑排序和创建顺序逆序两种反向传播 |

v2 保留自提交 `9b4f865` 的实现; 提交 `fbf0725` 中引入的 Graph 版本移至 v3.

运行示例:

```sh
make -C v3 run
make -C v3 test
make -C v3 time
```

将 `v3` 替换为 `v1` 或 `v2` 可运行对应版本. v0 仅提供 `run` 示例.

各版本的设计说明见对应目录中的 README.
